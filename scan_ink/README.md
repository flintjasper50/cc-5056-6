# 扫描线稿着色合成器

从带纸张底色、轻微阴影、抗锯齿墨线的扫描图中提取**可编辑线稿层**，在其下
铺设区域颜色，输出保留笔触细节的画面。全部为真实像素运算（numpy/PIL），
不使用乘法混合捷径，也不做全图二值化。

## 成像模型（显式、可复核）

逐像素、逐通道的凸混合模型：

```
I = (1 - b)·P + b·K
```

- `P` 纸色场（3 通道，含纸纹与光照渐变）
- `K` 全局墨色（深灰/带色墨，暗像素稳健中位数估计）
- `b` 有效墨覆盖率 alpha；抗锯齿边缘是分数值，浅笔触是小的 `b`，
  不会被截断成 0，也不被二值化

进一步拆分笔压：`b = a·t`，其中 `a` 几何覆盖率、`t` 笔触强度（局部 95 分位
估计）。三张图都可在界面查看，灰度笔触的去向可追溯。

### 各层如何估计

1. **纸色场 P**（`model.py: estimate_paper_field`）
   - 可靠纸区：冷启动取局部亮度峰值附近像素（适应阴影），用户画笔可补充
   - 观测先做亮侧分位滤波，去掉细墨点与纸纹低谷
   - 低频基色用**软锚定扩散**（有限权重拉向观测 + 邻域调和），墨洞由邻居
     填充；软锚定保证用户误标浅墨也不会把笔迹吸进纸色
   - 纸纹包络单独扩散保留，避免浅纸纹被误判成浅墨
2. **墨色 K**：最暗 `ink_dark_fraction` 分位像素的逐通道中位数；带深色
   纸底保护
3. **alpha b**（`model.py: estimate_ink`）
   - 解析解 `b* = <P-I, P-K> / |P-K|²`，物理裁剪到 [0,1]
   - 纸纹门限：残差低于 `k·局部纸纹尺度` 判为纸纹（局部尺度只统计纸面
     像素、排除墨迹），不是按亮度把亮像素直接设透明
   - 低可信度填充区额外收缩，抑制假笔迹
4. **合成**（`model.py: composite`）
   `out = (1-b)·under + b·K`，`under` 永远是新底色/区域层，原纸色 P
   不参与 → 墨缘夹带的旧纸色不会形成白边

### 诊断产物

- 残差热图：`I - 重建`，模型失配集中在抗锯齿边缘
- 失墨热图：单向暗化残差（原图比重建更暗），空间聚合后暴露结构性失墨；
  提高门限故意剪笔时，浅笔区失墨信号是纸面的 1.5 倍以上
- 深/浅两种底色重铺视图，直接查白边与失墨

## 数值验证（合成真值素材）

`python -m inkline.cli test --out output/tests` 生成 `report.json` 与全部
诊断 PNG。素材由 `synthetic.py` 以**已知 K、alpha、有色纸底**经 2x 超采样
合成（粗轮廓、1px 细线、浅铅笔排线、45° 交叉线、纸纹、阴影、传感器噪声、
墨缘纸色污染）。当前结果：

| 指标 | 值 |
|---|---|
| alpha 平均绝对误差（估计纸色） | 0.0034 |
| alpha MAE（给定真值纸色） | 0.0008 |
| 浅笔触（真值 b∈.05–.35）召回 | 0.93 |
| 极细线漏检率 | 0.000 |
| 污染边深底白边比例 | 0.000 |
| 二值化对浅笔触的摧毁比例 | 1.000（对照，证明不能二值化） |
| 乘法混合底色漂移 / 本模型漂移 | 13.6× |
| 改参数后原件是否变化 | 否 |

## 墨线分离验收（pytest，期望值独立推导）

`python3 -m pytest tests/ -q` 运行 18 个验收用例，分五个文件：

- `test_coverage_baselines.py`：**两路独立参照互证**。解析覆盖基准
  （`analytic_line_coverage` 的几何盒核闭式解）与独立超采样重合成
  （`triple_layer` 在 4x 密网格上对同一物理盒核做面积积分）在空间支撑、
  墨量级别、逐像素相关性上互证。两路代码互不共享，任何一路退化都会被
  另一路拦下。
- `test_ink_separation_acceptance.py`：细交叉线 + 偏色暖纸的**正反例**。
  正例断言覆盖率不丢笔、不系统性欠读，背景残差落在由已知噪声 sigma 推导
  的地板内，且保留分数笔触（非二值）；反例注入错误底色，同一残差断言
  必须失败（`pytest.raises(AssertionError)`），证明阈值不是宽松默认值。
- `test_fault_localization.py`：透印/淡墨/网纹**三重重合图**上分别注入
  纸色错误与混合次序错误，断言可从失败区域判别出错层——纸色错误使含纯
  纸区在内的所有分区残差整体抬升；次序错误只在淡墨/重合区抬升、纯纸区
  维持噪声底。
- `test_controlled_fault_evidence.py`：受控错误的**证据映射**。残差/覆盖率
  通道的判据全部回溯到独立参照量；常数伪参照因不含结构信息被显式拒绝，
  杜绝"取不到参照就用默认值放行"。
- `test_regression_legacy.py`：旧合成样例与既有 8 组数值验证**运行到底**，
  关键历史指标（alpha MAE、失墨抬升、白边、乘法漂移、二值化破坏等）不
  退化，诊断 PNG 落盘可供人工复核。

### 解析覆盖基准 vs 独立超采样的权衡

- 解析覆盖（`analytic_line_coverage`）：盒核与像素方块相交面积的闭式公式，
  确定性、零随机噪声，作为**墨量级别的基准**；但只对理想盒核成立，无法
  表达多级凸混合与传感器噪声。
- 独立超采样（`build_triple_scene`，4x 密网格对同一盒核求值 + 均值降采样）：
  用不同的求值路径重合成整幅图，产出 `alpha_faint_ref`、`recomp_ref` 等
  **重合成判定基准**，能捕捉离散化与三层嵌套混合的真实行为。
- 两者描述同一物理盒核，故应强相关、同量级、空间支撑一致；离散化差异
  有界（实测 level_ratio≈0.75、相关 >0.97、support_match=1.0）。

### 三重层注错的命令行产物

`python -m inkline.cli triple --out output/triple` 输出可在界面画布打开的
PNG（输入、真值纸色、参照/估计覆盖率、墨层、浅底合成、分区图）与
`triple_evidence.json`（两套注错的分区残差表 + 两路覆盖一致性）。

## 使用

```bash
# 验收测试（pytest）
python3 -m pytest tests/ -q

# 界面（浏览器，本地 HTTP，无第三方 web 框架）
python -m inkline.server --port 8765
# 打开 http://127.0.0.1:8765 ，点"载入合成素材"/"载入三重层回归样例"，
# 或用"上传扫描图"手动载入扫描稿后分离，查看墨线层与底色层

# 命令行
python -m inkline.cli demo --out output/demo            # 合成素材 + 全视图
python -m inkline.cli demo --fringe --out output/fringe # 墨缘污染场景
python -m inkline.cli triple --out output/triple        # 三层重合 + 注错证据
python -m inkline.cli run --input scan.png --out out    # 处理外部图
python -m inkline.cli test                              # 数值验证套件
```

### 界面操作（不只是脚本）

界面是扫描线稿流程的正式入口，启动方式即上面的 `python -m inkline.server`。
载入方式有三种：点"载入合成素材"生成带真值样例；点"载入三重层回归样例"
打开透印/淡墨/网纹重合图；或"上传扫描图"手动载入真实扫描稿。载入后在
左侧视图按钮切换**墨线层（中灰底显浅笔）/ 纸色场 P（底色层）/ 覆盖率
alpha / 浅底深底重铺 / 残差与失墨热图**。三重层样例下可用"受控注错"
按钮注入错误底色或颠倒混合次序，残差热图与指标面板会暴露坏结果。
所有图层都由 numpy/PIL 实际运算得到；运算异常不在页面崩溃，而是以顶部
红色横幅提示具体错误，指标面板同步显示"不可用"。

界面可分看：原件、纸色场 P、可信度 c、墨层（中灰底显浅笔）、alpha/a/t、
浅底/深底重铺、最终着色、区域层、原底重建、残差/失墨热图。画笔可标记
可靠纸区与保护细节；滑块改任一参数都从原件重新求值，原件永不被覆盖；
工程可保存/加载（原件、标记、区域、参数分别落盘）。
